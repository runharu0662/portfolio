  したがって開発にあたってdockerの基礎の学習と開発環境の構成を考えていきます.

## Dockerについて学習したこと
### colime
cliでの開発がメインであるため、dockerの実行環境として、GUIを使用する`DockerDesktop`ではなく、`colime`を使用しました。
dockerはlinux上で動作するため、macOS上でdockerを使用する場合は、dockerの仮想環境を構築する必要があったんですね。

colimeの起動
```
colime start
```
colimeの停止
```
colime stop
```
colimeの削除
```
colime delete
```

### Dockerfile
Dockerimage(コンテナのひな形)の設定ファイルです。Dockerfileを作成することで、コンテナの環境を定義できます。

### DockerCompose
複数のコンテナをまとめて管理するための設定ファイルです。docker-compose.ymlを作成することで、複数のコンテナをまとめて起動・停止できます。
